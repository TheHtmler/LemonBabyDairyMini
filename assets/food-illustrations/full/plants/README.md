# 植物类具体食物插画

本组对应系统食物库一级分类 01～07，共 838 条食物，使用 588 个具体食物视觉资源；其中新增 572 张 JPEG，复用原有 16 张具体食物插画。

插画通过内置 image_gen 工具生成，沿用 common-atlas.png 的暖白底、柔和精细手绘风格。未使用分类图、通用图或程序绘制占位图。原料、粉末、面条、干制、泡发、生熟、罐头等不同形态分别处理。

`manifest.json` 为最终映射；`atlases/batch-*.json` 记录每格食物、提示词、行列及原始图集路径，旁边的 `.prompt.txt` 保存完整生成提示词。26 张图集包含 24 张主批次与 2 张定向补图，编号较大的补图覆盖同一资源的早期格子。

对容易混淆的形态专门补图：干虾蓉挂面、荞麦面粉、莜麦面粉、干藕粉、桂花干藕粉、熟豇豆粒、脱水洋葱、布朗李子、松籽、小山核桃。另拆分大薯与山药、蒲公英与苦苣菜、黄蘑与元蘑、杏核仁与巴旦木。

需要从现有原图集重新生成最终 JPEG 时，在项目根目录运行：

```sh
python3 "assets/food-illustrations/full/plants/crop_atlases.py"
```

`prepare_*.py`、`refine_*.py` 保存分组和提示词整理过程；最终复现缩略图使用上述裁切脚本即可。裁切采用本机 ImageMagick，192×192、JPEG 质量 82，每图不超过 30KB。

静态资源检查：838 条映射全部覆盖；588 张图均为 192×192 JPEG，最大 10,077 字节；资源 JPEG 共 3,728,581 字节，其中新增 JPEG 共 3,643,491 字节。已检查图集数量、格序与基本食物形态。未新增或执行单元测试，未进行界面验收，也未启动服务。
