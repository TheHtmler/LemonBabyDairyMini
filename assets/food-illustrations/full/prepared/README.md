# 加工食品、调味品与其他食材插画

本组覆盖系统种子库一级分类编码 13～21 的全部 444 条记录。使用内置 `image_gen` 生成 15 个食品图集，再按已核对的格子位置裁切为 192×192 JPEG，质量 82；没有调用外部图片 API。

- `manifest.json`：系统食品编码与专用素材的最终映射。
- `images/`：314 张新生成的食品插画；另有 1 张素材复用项目既有 `bread.jpg`。
- `asset-plan.json`：食品形态、生成提示词描述、最终图集及格子索引。
- `atlas-order.tsv`：最终使用的图集行列、素材标识和种子食品编码。
- `atlases/`：原始图集及逐图提示词；01～13 为六列四行，14 为三列两行，15 为两列一行。
- `build-assets.py`：从实际生成图集重新导出 JPEG 和清单，不访问网络。

插画采用暖白底、接近实物的细致手绘表现。茶叶与茶汤、固体饮品粉与饮料、果汁与汽水、不同馅料月饼、软糖与硬糖、固体动物油与液体植物油、具体酱料、腌菜和草本食材均分别表达。仅外观相同的强化食品、品牌酒类以及普通金黄色植物食用油等共享真实具体食品形态；未使用任何分类占位图。

已人工查看生成图集核对主体与位置。14 图集重绘麻辣酱、干高良姜、金钱萝卜、苦豆子调味干叶及鲜车前子形态，并补齐鱼丸。15 图集补充不显示内馅的整形月饼，供未明确馅料的品牌月饼使用，同时将棉花糖修正为软质短圆柱糖果。原先图集保留作为过程资料，清单只引用纠偏后的格子。

核对形态时参考了原种子记录的名称、含水量与营养构成，以及下列公开资料：

- [蛋片的实际薄片形态（金翼食品）](https://www.jinyi-food.com/zh-cn/egg-flake)
- [苦豆子叶作为香豆调料的用法（中国海洋大学）](https://aoc.ouc.edu.cn/2018/0711/c9821a206965/pagem.psp)
- [奶糕的米粉成形、蒸熟与烘干形态（汉语词典）](https://cd.hwxnet.com/view/jggaonjbaonmdnbp.html)

验收仅限图像素材本身及清单、文件、尺寸、格式和大小等静态完整性核查；没有执行界面或交互验收，没有新增或运行单元测试，没有启动服务、提交、推送或调用生产接口。
