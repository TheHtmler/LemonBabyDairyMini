# 识别弹窗沿用添加表单布局

**需求：** 直接落实用户反馈，沿用当前分支及会话。名称、分类、基准、营养和蛋白来源采用现有添加页的单列标签与输入框；仅保留一处「来自AI估算」，不再逐字段展示手填／来源／采用建议。第三步为「识别营养」，关闭图标使用固定线条。

**约束：** 不增改单元测试、不启动微信工具、不调用真实模型或数据库、不提交或部署。保留上传、识图、营养查询的真实渐进状态、手填保护、特殊蛋白规则、回填与保存协议。

## 实施与验收

- [x] 重排单列必填及扩展信息、修正关闭按钮、精简状态与来源文案。
- [x] 生熟状态只在必须确认或主动调整识别时展开；调整后重新核对，不混用旧估算。
- [x] 执行既有回归、构建一致性和静态检查；用本地合成输入检查手填切换、阶段状态、窄屏和奶粉布局；完成一次独立审查并记录边界。

**验收重点：** 改成手填后各行结构和高度不变；全部AI营养改手填后标识消失；无必要时不展示生熟选项，但能主动修正；特殊蛋白仍须确认；取消不回填，只有使用结果回填。
