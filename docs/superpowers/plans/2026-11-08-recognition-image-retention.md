# 识别图片留存实施计划

依据：用户已确认的留图方案。沿用微信云开发，不引入新服务或依赖。

约束：保留现有未提交改动；不提交、不部署、不操作线上文件；不新增单测，不做界面验收。

- [x] 食物保存一张封面；包装保存封面和营养表，识别输入不变，两个保存入口共用选择规则。
- [x] 报告结果页提供默认关闭的“保存原报告”；本地照片到表单后才按用户选择上传到独立私有目录。
- [x] 报告保存、编辑、详情回看、删除支持附件；服务端校验宝宝成员关系与报告归属，图片功能不依赖 OCR 额度。
- [x] 提供仅覆盖识别临时目录的生命周期配置及私有目录发布说明；权限确认前默认关闭报告原图保存入口。
- [x] 执行 JavaScript 语法、依赖及模板表达式静态检查，记录发布限制，不调用真实云端。尚未重新执行微信模板编译与界面验收。

重点核对：切换宝宝或账号不串图；编辑旧报告不丢附件；识别临时图不作为永久附件；包装证据索引失效时不误选；云端删除只接受报告已引用的附件。
