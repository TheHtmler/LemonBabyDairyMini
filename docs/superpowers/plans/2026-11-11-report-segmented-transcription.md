# 报告识别分块处理实施计划

用户已授权优化长报告的输出上限处理；取字不得依赖报告类型或固定指标规则。

1. 在服务端按原像素裁图，分离核心取字范围和上下文范围，并在图外用蓝色边栏标记核心；按名称文字中心归属，保留倾斜或换行项目的上下文，读不全的单元必须为空。
2. 单块超限或原行结构不合格时，丢弃该次输出并将当前块二分，复用已成功的块；限制拆分深度、调用次数、并发及总耗时。
3. 全部图片块完成后固定来源编号，按少量原行分批分类，分类超限继续细分；最终统一校验并汇总，任何未完成块均不能产生成功回填。
4. 增加图片块、拆分原因、分类批次等无检验原文的诊断；更新内部版本、构建云函数共享文件并执行语法及静态构建检查。

约束：不新增、修改或执行单元测试，不进行界面验收，不上传样本或调用真实模型，不部署、提交或推送。重叠区的重复原行保留来源，由现有候选核对逻辑合并同值并提示异值；不得按名称猜测去重。
