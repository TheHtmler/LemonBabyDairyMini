# 管理员 AI 模型与免费额度设计

> 2026-10-31 按用户反馈修正：配置页用于持久保存模型选择和按需查看额度。额度查询不再是保存或调用的前置条件，旧的“15 分钟未同步暂停 AI”规则已撤销，详见 [调用与额度查询解耦记录](../../verification/2026-10-31-ai-quota-decoupling.md)。

## 目标与边界

在现有管理员配置菜单新增“AI 模型配置”，管理搜索与营养识别（含文字营养估算）的模型顺序、准入和启停，查询百炼真实免费余额，到期或免费额度耗尽后自动选择下一项。

复用微信云开发与 `featureFlagManager` 的服务端管理员校验，不创建额外服务器，不提交、推送或部署。不新增或修改单元测试，不执行界面或交互验收。现有搜索界面未提交改动原样保留。

## 已验证事实

- 本机百炼 CLI 2.7.2 已登录；北京业务空间 18835336 的七个候选均可查询，免费保护均已开启。
- 当前搜索 `qwen3.5-122b-a10b` 剩 797138 Token，当前识别 `qwen3.7-plus` 剩 349857 Token；其余五项各 1000000 Token；到期日均为 2027-01-08。这些是查询快照，不写死为实时数据。
- `bl usage free --output json` 返回 model、remaining、total、expires、autoStop 等字段。其 type 字段把图文模型也分类为 Text，不能据此判断是否支持图片。
- CLI 2.7.2 的续期实现是 `refreshAccessToken`：控制台令牌失效后使用配置中的 AK/SK 调用 `GenerateCLIAccessToken`；仅浏览器登录不等于拥有永久续期能力。
- 本机凭证不复制上云。云端的控制台令牌与专用访问凭证由部署者配置。未配置时同步返回明确状态，保留上次成功快照。
- 2026-10-31 确认现有查询函数为 Node.js 16.13、60 秒超时。CLI 要求 >=18.17，最终改为 Node.js 内置 HTTPS 调用相同官方网关，不在云端运行或安装 CLI；真实 Node.js 16.13.0 已只读查询七个候选成功。

## 配置与数据

复用服务端 `feature_flags`，所有文档禁止小程序端直读写，管理员通过云函数访问。固定文档 ID 避免多条配置：

- `ai_model_config`：version、enabled、场景列表、updatedAt、updatedBy。enabled 为整个管理策略启用开关；首次未保存时继续使用现有环境变量策略。显式启用后不回退环境变量名单。
- `ai_model_quota`：models（按代码索引，含真实余额、总额、到期日、autoStop）、checkedAt、lastAttemptAt、syncStatus、syncError、锁到期时间。查询失败不覆盖 checkedAt 和 models。
- `ai_model_state_<模型代码>`：免费额度不可用的持久标记、阻断时间、原因；成功请求和余额同步都不自动清除耗尽标记。
- `ai_model_runtime_<场景>`：最近实际模型、最近调用时间、最近切换原因。只存模型运行信息，不存宝宝数据、输入或图片。

配置保存使用版本号事务防止覆盖；失败不得先修改运行配置。启用状态保存时至少一个场景选中已核验模型，关闭 AI 始终允许保存。保存不读取额度快照或运行阻断状态；运行时仍跳过接口已确认耗尽的模型。服务端返回公开管理数据，绝不返回访问令牌或 API Key。

## 调用选择与切换

由共享 `packages/ai-access-core` 实现数据库策略读取和状态写入；搜索、识别云函数通过构建脚本同步共享代码。

管理策略启用后，按保存的场景名单选择能力匹配、enabled、verified 且未被接口确认耗尽的模型。业务策略不读取额度快照，不因快照缺失、超过 15 分钟或同步失败而停止服务，也不在业务请求中临时查询额度。15 分钟仅用于页面提示数据较旧；查询时的余额、到期日与保护状态只用于展示，不证明调用时仍然有效。允许官方北京 OpenAI 兼容接口：旧共享域名 `dashscope.aliyuncs.com`、单一业务空间域名 `{WorkspaceId}.cn-beijing.maas.aliyuncs.com` 和试用域名 `trial.cn-beijing.maas.aliyuncs.com`，均使用 HTTPS 与 `/compatible-mode/v1` 路径；拒绝其他地域、任意代理、非默认端口及携带凭证/查询参数/片段的地址。地址与模型调用 Key 继续使用各业务函数现有环境变量，不随模型名单迁入管理员菜单。

额度到期日按北京时间展示；运行中是否到期或耗尽由模型接口返回确认。别名和快照作为独立额度池；同一代码跨场景共享耗尽状态。

维持一次搜索业务请求最多两次底层模型调用、约 10 秒总时间；识别最多两次、约 25 秒。纠错和备用共用搜索调用预算。已知不可用模型在调用前全部跳过；一次请求最多尝试两个候选，后续请求从剩余可用模型继续。

仅明确 `FREE_QUOTA_EXHAUSTED` 永久标记免费不可用并切下一个。限流或临时服务错误可在剩余调用预算中切换，不记为余额耗尽；鉴权、接口参数错误不盲目轮换。总截止时间不因换模型而重置。

全部不可用时返回现有 AI 不可用错误；搜索沿用现有真实名称查询降级，识别沿用手动录入入口。每日业务次数继续按原规则计数，不能每次模型切换多扣一次业务次数。

模型状态持久化失败时终止本次轮换，避免不可信状态继续扩散。意图缓存包含管理配置版本，避免名单修改后复用旧策略身份。

## 免费额度采集

共享采集器使用 Node.js 16.13 可用的内置 HTTPS 和加密模块，按官方 CLI 2.7.2 的协议访问固定北京控制台网关，仅查询代码内七个候选的余额和免费保护。不接受前端传入接口地址、模型目录或凭证；无新增 npm 依赖、子进程或临时凭证文件。

`featureFlagManager` 新增管理员 action：getAiModelConfig、updateAiModelConfig、refreshAiModelQuota。查询状态和配置可在没有同步凭证时工作；刷新缺少凭证返回可操作错误。刷新用数据库锁合并并发，成功后 60 秒内返回缓存。

新增 `syncAiModelQuota` 云函数，五分钟定时触发。定时入口要求无小程序 OPENID，且是配置的定时事件；普通小程序调用不能触发。管理员“立即刷新”在 featureFlagManager 内调用同一采集器，不借用定时入口绕过校验。

余额与免费保护两个只读接口并发查询，两者均成功且字段严格校验通过才保存快照。整个查询及可选续期共用 25 秒截止时间，每份响应最大 1 MiB。错误对外仅返回固定中文类别及阶段、Node 版本和 HTTP 状态等脱敏诊断，不回显请求头、响应原文或配置。

环境配置：BAILIAN_QUOTA_ACCESS_TOKEN 为控制台访问令牌；BAILIAN_QUOTA_ACCESS_KEY_ID、BAILIAN_QUOTA_ACCESS_KEY_SECRET 为可选续期凭证；BAILIAN_QUOTA_SECURITY_TOKEN 为可选 STS 凭证。续期凭证必须成对配置；不把模型调用 Key 当查询授权。无独立续期凭证时页面明确提示令牌可能需要更新。首次部署先验证令牌导入和查询，再验证续期权限，最后开启定时触发。

仅明确鉴权失败且配置完整专用访问凭证时，按官方 ACS3 签名协议续期一次并重试查询。新令牌仅缓存于当前函数实例内存，不写数据库、环境变量或日志；实例冷启动仍依赖原始令牌或专用续期凭证。自动续期的云端权限尚未实测，不能据源码存在就承诺长期无人值守。

不承诺剩余 Token 逐次实时准确；百炼免费保护为服务端费用边界，本地余额和同步快照仅供管理员查看。应用不更改百炼端保护开关；取消本地快照拦截后，不能把配置保存或模型入选视为免费保护已开启的证明。同步失败不关闭保护、不更换调用地址或密钥。

## 管理员页面

沿用现有暖色管理页样式，新入口与“营养识别次数”等并列。页面保留服务总开关、search/scan 标签、当前状态和刷新额度、紧凑模型顺序列表、底部固定保存栏。每个模型仅保留一个启用按钮和上下移动；新候选首次启用时明确确认业务效果已核验，替代两组独立开关。模型显示简短名称、余额与到期日；精确编号、最近运行、切换原因和较长说明放入默认收起的“运行详情与说明”。

额度刷新与模型选择、配置保存、服务调用独立。刷新失败直接展示具体的授权、网络、超时或返回异常信息，不以“暂无符合条件的模型”代替错误原因。额度尚未查询、较旧查询结果和接口已确认耗尽分别显示；已选中并核验的模型可保存，不要求先刷新额度。列表标明“已加入调用顺序”和查询时保护状态，不将名单入选描述为免费保护已验证。

显示“最近实际使用模型”与“按当前资格预计使用模型”，不用全局单一“当前模型”误导并发场景。保存期间禁用编辑；版本冲突提示重新加载，保留用户草稿供判断。切换账号、退出页面后忽略旧异步响应。

不在页面输入任何云端密钥。未配置同步授权时显示配置提示，不能用历史预填余额冒充成功同步。未部署云函数时显示明确加载错误。
