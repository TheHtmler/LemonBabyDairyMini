# 报告分析：参考图改版与报告比对

日期：2026-11-04

状态：用户认可紧凑原型后已实施；静态验证完成，界面验收尚未授权。
工作分支：`codex/report-analysis-focus`

## 目标与依据

用户希望报告分析参考三张截图，并加入报告比对。截图提供布局参考，其中人物姓名、检查号、疾病和数值不作为本项目数据或医学规则。

现有代码已有报告档案、双报告指标对比和检测前 7 天饮食背景。本轮复用这些能力，调整信息层级、打通详情到比对的路径，并修正缺失值与变化方向的展示问题。

本方案补充同目录 `2026-11-04-report-analysis-focus-design.md`，原文件保持不变。发生布局冲突时，以本方案为准；下文完整列出本轮实现约束。

## 页面结构

用户查看首版原型后明确要求：默认入口应为报告列表和报告对比；列表及详情文字偏大、留白过多，需要提高信息密度、降低滚动成本。以下布局已按此反馈修订，覆盖原先的最近报告大摘要与宝宝形象方案。

一级入口为「报告列表」「报告对比」，默认打开报告列表，单份报告使用独立详情页。

### 1. 报告列表：直接展示紧凑档案

从上到下：

1. 报告类型筛选，包含「全部」以及项目现有七类报告，空类型仍可选择。
2. 小型工具行：当前宝宝、报告数量、文字「添加报告」入口。
3. 连续报告列表：日期倒序；左侧显示月日与年份，右侧约两行容纳类型、超范围状态、机构与录入数量，细分割线替代独立大卡片。点击整行进入详情。
4. 不再添加最近报告摘要、问候语或插画，避免首屏重复展示最新报告并挤压列表。
5. 添加报告复用拍照识别与手动录入流程，预选当前筛选类型；「全部」时先选类型。

类型筛选更新整个列表。默认对比类型优先使用当前选定类型；从「全部」进入则使用当前宝宝最新报告的类型，不默认切换到数量最多的类型。

不复用参考图的成人医生大横幅，避免挤占实际报告信息。当前工程选择保留项目暖奶油底色、柠檬黄主操作，以低饱和青绿表示参考范围内状态；这是待确认的设计选择，用户尚未指定改成整页绿色。

### 2. 单份详情：紧凑明细表

顶部信息压缩为导航标题和两行元信息：报告类型、检测日期、机构、宝宝、已录入数量和超范围数量。正式实现保留编辑入口，检查号没有对应数据时不展示。

移除宝宝插画、重复的重点指标概览、大数字及每项占一整块的范围条。指标以「项目／检测值／参考范围」三列紧凑对齐，缩写与单位作为次行，异常使用文字、箭头和颜色共同表达。

采用普通页面滚动，不实现拖拽抽屉。设计目标为报告行约 60–70px、指标行约 44–54px，长项目名自然换行，不截断关键信息；正文约 13px、数值约 14px，按钮保留触控面积。具体屏幕密度尚未进行界面验收。

- **完整报告**：默认栏，显示全部指标，沿用配置顺序与已有分组，未知／未录入按实际状态标注。
- **仅看异常**：快速筛选当前报告所有超范围指标，角标为超范围数量。筛选时仍使用同样的紧凑三列表格，不恢复大卡片。

当前没有经过审核的疾病解释或建议数据源，因此只展示报告记录和参考范围状态，不生成诊疗建议。已有真实备注字段如可用可原样展示，不凭空补充。

底部「与上一份对比」带入当前报告和类型；有其他同类报告但无更早报告时显示「选择报告对比」，只有一份时显示「添加同类报告」。正式实现保留复制，删除只保留一处次要入口和现有确认流程。编辑返回刷新明细与可对比报告。

### 3. 报告比对：打开即看到结果

```text
报告列表                         报告对比
报告类型

对照报告                         本次报告
日期 · 机构                      日期 · 机构
切换 / 查看                      切换 / 查看

可比较 N 项 · 升高 X · 降低 Y · 相同 Z
数据不足 M 项

显示 N/N 项                      展开指标筛选
项目 / 单位        对照值       本次值       差值
……                 ……          ……          ……

只看重点指标
展开核对参考范围
检测前 7 天饮食背景               展开
```

视觉上左边为对照、右边为本次，所有选择器、吸顶列头、指标行和饮食背景都使用同一顺序。代码中现有 A/B 命名可以在内部保留，但视图模型必须显式映射，不能只交换标题。

默认本次为最近报告、对照为前一份同类报告。从详情进入时本次固定为该报告，优先选检测日期严格更早的最近同类报告。没有更早报告时进入选择状态，要求用户选择其他同类报告，不悄悄把未来报告称为「上次」。从总入口默认选中同日的两份报告时，只标「本次／对照」，不宣称时间先后。

用户可切换任一报告或交换双方，不能选同一份报告；同日报告选项附机构及可用的创建时间或短标识区分。更晚的报告可以被手动选为对照，仍明确按「本次 − 对照」计算。

默认展示任一侧有值的全部指标，以四列紧凑表格展示「项目／对照／本次／差值」，本次列轻底色强调。支持「只看重点指标」，此时优先超范围再补关键指标、最多四项；按配置顺序稳定排列，不按跨单位差值排序。参考范围可展开核对，正式实现遇到范围差异时仍需直接提示。指标筛选默认收起，自选至少保留一项。切换类型或报告组合恢复全部指标，避免沿用上一组筛选。

摘要统计全部任一侧有值的指标，并标注「全部已录入指标」，不随四项预览或自选而悄悄变化；可比较数等于升高、降低、相同之和，单侧缺数值计入数据不足。全部无值时显示「尚无可比对指标」并提供查看／编辑入口，不显示无变化结论。

只展示数值升高、降低、相同和两侧参考范围状态，不将升降称为好转或恶化。本轮不增加多报告趋势、新增异常／恢复正常统计、自动解读或复查通知。

## 数据与状态口径

- 严格限定当前宝宝的同类报告，使用现有报告类型和指标键对齐，禁止按相似名称模糊匹配不同指标；切换宝宝清除旧选项及详情上下文。
- 保留数值零；空字符串、纯空白、null、undefined、无效数值不是零；任一侧不是有限数值时不计算差值。
- 展示状态根据当前有效数值与该报告的参考范围派生，不使用清空数值后残留的历史状态，不回写历史报告。
- 显示「偏高／偏低／参考范围内／待核对／未录入」，无超范围项但状态不完整不能称为「全部正常」。缺范围和已有范围但无法判定分别说明。
- 不改变已有医学阈值算法；详情支持零边界和单侧参考范围，不因真值判断丢失零值。
- 差值统一为本次减对照；箭头和文字同向。升降使用中性色，红色仅表达超范围，且始终搭配文字。
- 参考范围不一致时分别显示并提示。单位目前来自类型配置而非每份原报告，本轮不新增单位字段或自动换算；页面简短提示核对原报告单位与参考范围，不声称已验证跨机构可比性。
- 没有报告时提供「录入第一份报告」；只有一份时提供「添加同类报告」。加载失败提供重试，刷新失败保留已加载内容，不能把错误伪装成空档案。
- 录入／编辑返回刷新最近摘要、时间轴、详情与当前比对；缓存命中也处理聚焦请求。切换宝宝、类型或报告后，过期异步请求不能覆盖当前结果。

## 饮食背景

放在报告比对结果之后，默认收起，展开才加载，支持收起和失败重试。分别标明两份报告检测前七天的日期范围与各指标有效记录天数，不将缺失记录补零。

历史体重系数使用对应日期汇总中的有效体重（沿用服务既有历史测量顺延口径），不能套用宝宝当前体重；不宣称为当天实测。平均值只计算有效数值，每个指标分别统计覆盖天数。两组同一营养指标共用柱图尺度，不据此推断饮食与化验变化存在因果关系。

## 实施范围

- `miniprogram/pages/analysis-report/index.js`、`index.wxml`、`index.wxss`：概览、时间轴、比对布局、选择及状态联动。
- `miniprogram/pkg-report/report-detail/index.js`、`index.wxml`、`index.wxss`：宝宝概览、重点与完整分栏、比对入口、编辑返回刷新。
- `miniprogram/utils/reportWorkbench.js`：共享展示数据、重点选择、差值方向、缺失状态、饮食背景有效覆盖率；必要时提取小型展示工具以免继续扩大该文件。
- `miniprogram/models/reportRepository.js`：必要的查询错误传播，仅对明确不存在的集合保留现有兼容行为。
- 按实际需要调整上述页面配置，沿用现有路由、存储、权限和录入字段，不引入依赖、数据库变更或新后端服务。

保留用户已有未提交文件。已按用户认可的紧凑布局实施；不提交、推送或合并。

## 验证与完成标准

只运行 JavaScript 语法、已有小程序依赖静态检查和差异检查，条件允许时做模板静态检查。静态核对零／单／多份报告、同日报告、零值、缺值、参考范围差异、重复选择、切换宝宝、旧请求回写与失败重试路径。

不新增、修改或扩充单元测试。不启动开发服务，不执行浏览器、模拟界面、截图或交互验收；界面验收须另行说明目的与范围并获得用户明确同意。修改后刷新 code-index 索引。

完成标准：从紧凑列表打开完整详情、直接读取多项指标，从详情一键进入同类比对；默认比对先给结果，变化方向与两列含义始终一致，未知和缺失数据如实呈现。
