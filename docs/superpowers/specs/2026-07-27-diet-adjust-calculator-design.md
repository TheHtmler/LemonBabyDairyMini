# 饮食调整换算设计（简化完整版）

日期：2026-07-27  
状态：已确认（比例范围 + 可搜索选品 + 汇总展示）  
分支：`feature/diet-adjust-calculator`

## 背景

宝宝阶段性调整饮食结构（少普奶、多辅食、种类变多）时，需要在**蛋白系数或热量系数大致不变**的前提下，换算各品项用量。界面需对低学历用户友好。

## 目标

1. 主目标：保蛋白或保热量（体重 × 系数，可手改）  
2. 一条滑条：奶 ↔ 辅食  
3. 从奶粉档案 / 食物库**搜索添加**品项（不整页罗列）  
4. 自动算各品项**具体 g/ml**；能量粉只补热量  
5. 「更多目标」为**比例范围**（月龄默认，可手改）  
6. 结果区展示类似数据记录的营养汇总，并标注是否落在范围内  
7. 微调后覆盖应用到某一天  

## 非目标

- 阶段方案模板库  
- 肉/菜/水果占比手填  
- 按一日 N 顿均分喂奶  
- 品项推荐量用区间（冲奶/盛辅食必须用具体数量）  

## 入口

- 「我的」→「饮食调整换算」  
- `pkg-misc/diet-adjust-calculator/`  

## 用户流程

### 1. 今日目标

- **保蛋白 / 保热量** + 具体目标值  
- 保蛋白时可填热量参考（能量粉补热）  
- **更多目标（比例范围，%）**  
  - 蛋白供能、脂肪供能、碳水供能、优质蛋白占总蛋白  
  - 默认按宝宝月龄填充（见下），可改上下限  
  - 清空某项上下限表示不考核该项  

### 2. 大类比例

- 滑条：奶多 ←→ 辅食多  

### 3. 添加要吃的

- 分组：普奶 / 特奶 / 能量粉 / 辅食  
- 已选为可删除标签；点「添加」打开弹层，**可搜索**，数据来自营养档案奶粉与食物库  
- 辅食最多 5 种；不填组内份额，同类自动均分  

### 4. 算一算

- 各品项给出**具体 ml/g**（可微调）  
- 能量粉注明「用来补热量」  
- **营养汇总**（对齐数据记录心智）：蛋白（可含天然/特殊若可算）、热量、脂肪、碳水、优质蛋白；以及蛋白/脂肪/碳水供能比、优质蛋白占比，并标注相对范围：在范围内 / 偏低 / 偏高  

### 5. 应用到某天

- 覆盖写入规则不变（删奶+辅食 → 写全天总量 → markDirty）  

## 月龄默认比例范围

| 指标 | 默认 |
|------|------|
| 蛋白供能 | 10%～15%（与数据记录参考一致） |
| 碳水供能 | 55%～60% |
| 脂肪供能 | 0–6 月 45%～50%；其后按现网月龄档：约 35%～40% / 1–2 岁 30%～35% / ≥6 岁 25%～30% |
| 优质蛋白占总蛋白 | **30%～50%** |

说明：各供能参考带可重叠合计超过 100%，与现网「分别对照」一致，不作硬性互斥拆分。

## 换算算法

- 主目标分配、能量粉补热、同类均分：与简化版一致  
- 软目标改为比例范围对照；优质蛋白不足时可对辅食做小幅偏向优质的再平衡  
- **不保证**比例一定落入范围，不阻塞应用  

## 数据写入 / 校验

与简化版一致；软目标未达标仅提示。

## 成功标准

- 用户不手填多层份额；用滑条 + 搜索添加 + 算一算即可  
- 份量为具体数字；目标与达标判断用比例范围  
- 结果区能看懂营养汇总是否落在建议范围  
- 应用后该日奶/辅食被替换
