# 饮食调整换算设计（简化完整版）

日期：2026-07-27  
状态：已确认（选品复用 + 双系数主对照 + 行内营养）  
分支：`feature/diet-adjust-calculator`

## 目标

1. 主目标强行对齐：蛋白与热量系数都可启用，**必须指定一个为主**；对照目标只展示/驱动补热，不反向拆份额  
2. 滑条：奶 ↔ 辅食  
3. 选品交互与现网一致：  
   - 奶：喂奶录入同款「选奶购物车」弹层（我的/系统、分类侧栏、+/购物车/确定）  
   - 食物：跳转 `food-picker`（`from=diet-adjust`，只选品不填份量）  
   - **食物数量不设上限**  
4. 推荐量为具体 g/ml，**每行展示换算营养**（蛋白/热量/脂肪/碳水，优质蛋白有则显示）  
5. 更多目标：月龄比例范围；结果汇总对齐数据记录心智  
6. 能量粉只补热量；应用覆盖写入某日奶+辅食  

## 双系数规则（方案 B）

- 可同时勾选蛋白系数目标、热量系数目标  
- 指定「为主」的一方：求解强行对齐（奶/辅食滑条分配）  
- 另一方为对照：  
  - 主=蛋白、对照=热量：热量对照驱动能量粉补热与汇总对照  
  - 主=热量、对照=蛋白：蛋白只展示差距，不改分配  
- 至少启用一个；若只启用一个，则其自动为主  

## 选品

- 奶：弹层确定后按品类归入普奶/特奶/能量粉已选列表  
- 食物：`food-picker` 回写 id 列表，本页映射为已选标签（可删）  
- 同类自动均分，无手填份额  

## 其余

算法、能量粉、比例范围默认、应用覆盖规则见前版；品项推荐量不用区间。
