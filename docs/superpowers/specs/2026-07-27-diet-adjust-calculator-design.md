# 饮食调整换算设计（简化完整版）

日期：2026-07-27  
状态：已确认（简化重设计）  
分支：`feature/diet-adjust-calculator`

## 背景

宝宝阶段性调整饮食结构（少普奶、多辅食、种类变多）时，需要在**蛋白系数或热量系数大致不变**的前提下，换算各品项用量。原四步向导要求手填多组百分比，对低学历用户不友好。

## 目标

提供简单完整的换算工具：

1. 锁定全日主目标（体重 × 蛋白/热量系数，可手改）  
2. 一条滑条设定「奶 ↔ 辅食」大类比例  
3. 预选普奶 / 特奶 / 能量粉 / 食物具体品项（不填份额）  
4. 自动算出推荐量；能量粉只补热量；脂肪/碳水/优质蛋白可设软目标并对齐展示  
5. 微调后覆盖应用到某一天  

## 非目标

- 阶段方案模板库  
- 肉/菜/水果占比手填  
- 按一日 N 顿均分喂奶  
- 数据记录页「选用模板」入口  

## 入口

- 「我的」→「饮食调整换算」  
- 路径：`pkg-misc/diet-adjust-calculator/`  
- 文案偏白话，弱化「试验」感  

## 用户流程（单页为主）

### 1. 今日目标

- 主目标二选一：**保蛋白** / **保热量**  
- 默认按体重 × 现有系数预填，允许手改  
- 展开「更多目标」：脂肪 g、碳水 g、优质蛋白 g（可选；有默认估算时可预填，允许清空表示不考核）  

### 2. 大类比例

- 一条滑条：奶多 ←→ 辅食多  
- 白话展示：如「奶约 70%，辅食约 30%」  

### 3. 勾选要吃的

- 奶分组：普奶（含母乳）、特奶、能量粉  
- 食物：从食物库多选，上限 **5**  
- 不填组内份额 %；同类自动均分  

### 4. 算一算 → 推荐量

- 展示各品项推荐量（可改）  
- 能量粉行注明「用来补热量」  
- 对照条：蛋白/热量/脂肪/碳水/优质蛋白 目标 vs 当前  
- 软目标凑不齐不阻塞，给白话提示  

### 5. 应用到某天

- 选日期 → 确认覆盖 → 删当天奶+辅食 → 按微调后数量各写 1 条全天总量 → `markDirty`  

## 换算算法

### 主目标分配

以保蛋白为例（保热量把蛋白换成热量）：

1. 全日主目标 `T`  
2. `T_奶 = T × 奶占比`，`T_辅食 = T × 辅食占比`  
3. **蛋白/主目标只分给「扛蛋白」品项**：已选普奶 + 特奶 + 食物；**能量粉不参与**  
4. 普奶与特奶都选时：奶侧再按现有 **天然/特殊蛋白系数** 自动切开；只选一类则该类吃满奶侧  
5. 同类多种 → 平均分份额 → `推荐量 = 分到的目标 ÷ 单位浓度`  

### 能量粉（只补热量）

1. 先完成非能量粉品项的主目标分配  
2. 用体重 × 热量系数（或用户填写的热量参考）得到热量对照值；保热量模式下热量对照即主目标  
3. 若勾选了能量粉且热量仍缺口：按热量浓度用能量粉补足（多种则均分缺口）  
4. 未勾选则只提示热量还差多少，不擅自加品项  

### 多指标软目标

- 主求解仍只按一个主目标 + 滑条 + 均分 + 能量粉补热  
- 脂肪/碳水/优质蛋白：算出后对比；优质蛋白不足且辅食中同时有优质/非优质时，可在辅食总量约束下小幅偏向优质食物  
- 脂肪/碳水偏差以提示为主；**不保证凑齐，不阻塞应用**  

### 微调

改数量后只重算达成与提示，不再自动改回求解量；应用以微调后为准。

## 数据写入

与既有覆盖规则一致：

1. 弹窗白话说明会清掉该日喂奶和辅食，其它记录不动  
2. 先删喂奶 v2 + 辅食（软删），再按品项写全天总量（08:00 起 +30min）  
3. `DailySummaryV2Model.markDirty`  
4. 删后写失败：提示到数据记录页检查补录  

## 校验

| 场景 | 行为 |
|------|------|
| 未登录 / 无宝宝 | 禁止计算与应用 |
| 辅食占比 &gt; 0 未选食物 | 不可计算 |
| 奶占比 &gt; 0 未选普奶/特奶（仅能量粉不够） | 不可计算，提示先选普奶或特奶，或把滑条移向辅食 |
| 缺浓度 | 标出品项，整体不算量 |
| 软目标未达标 | 可提示，仍可应用 |

## 成功标准

- 用户主要操作：调滑条、勾选品项、点算一算、微调、应用到日期  
- 能量粉不抢蛋白份额，只补热量  
- 脂肪/碳水/优质蛋白可看齐、可提示  
- 应用后该日奶/辅食被替换，日汇总可重建  

## 相对旧版变更摘要

- 去掉手填奶/辅食以外的多层百分比与组内份额输入  
- 单页 + 滑条替代四步强向导  
- 增加能量粉职责（补热）与软目标对照  
- 食物上限由 3 调整为 5
