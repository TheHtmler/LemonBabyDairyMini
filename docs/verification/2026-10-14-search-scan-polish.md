# 首页搜索与扫描优化验收

## 问题与本轮范围

用户在微信开发者工具本地预览时报告布局、间距、文字及图标比例不合理；搜索“青菜”没有结果，相册识别提示“拍照识别不可用，要手动添加”，随后显示“上传未完成”。沿用已经确认的首页搜索与扫描设计，本轮修复完整链路及相关界面，不扩大业务搜索范围。

约束：不新增或修改单元测试；保留工作区原有未提交改动；不提交、不推送；生产 API、部署、数据库结构及配置修改必须先取得用户明确确认。

## 根因与修复

- 系统食物源包含“小白菜[青菜]”。原搜索候选读取在资料来源全部扫描完成前返回空列表，即使已经有命中结果；每次只读取一条文档使首屏更慢。现在以最多 40 条文档分批读取，中文关键词先做保守单字预筛选，再由统一匹配器校验完整名称、别名和营养条件；已有命中立即返回，客户端按相关度合并排序。
- 只推进实际处理过的文档边界，预算用尽后未处理的批量文档仍可在下一页读取。异常来源保留继续查询状态，不阻断其余可用来源，不把不完整扫描误报为最终无结果。
- 搜索页不再因能力查询失败而静默忽略点击；普通搜索默认可提交，显式关闭及权限拒绝仍生效。智能额度故障不会连带关闭普通搜索。空扫描页会自动续查少量页面，仍保留手动继续入口。
- 普通名称中的“低蛋白”“高铁”等不再仅因单个描述词而被判为必须调用 AI；功能分类只查功能，食物等分类不再额外发起无关分类查询。
- 扫描页独立调用 `recognizeNutritionLabel.capabilities`，不再依赖搜索云函数的能力接口。区分功能关闭、模型未就绪、日额度用尽及连接异常；上传前核对模型配置。没有放宽免费保护、模型白名单、额度或服务端鉴权。
- 自定义分类独立加载并保留默认分类。相机首次就绪仅启动一次；图片压缩不受支持时，继续校验原图大小；双击及旧上下文响应受到隔离。
- 参考查询故障时，预览保留已有图片识别结果并提示重试；保存时仍须取得服务端比较版本，不伪造版本、不绕过保存校验。准备阶段失败显示“图片尚未上传，识别服务未就绪”，不再混同于实际上传失败。
- 首页通栏、搜索页和扫描页共用 36rpx 线性图标；重排输入区、提交、筛选、分类、结果、预览和拍照操作。重新约束控件行高、内边距、文字缩放、长名称换行和安全区。只显示扫描入口时，整条入口可点击。

## 本地验收证据

- 对真实项目中的 1,752 条系统食物数据执行内存数据库验收：首屏命中“小白菜[青菜]”，蛋白质 1.4 g，12 次离线数据库读取；能够打开资料预览。跨宝宝查询返回 `FORBIDDEN`。
- 直接调用搜索页面：模拟能力服务连接失败后，普通名称仍执行查询并展示青菜；“记录喂奶”可命中对应功能。
- 直接调用独立识别能力：缺少开关记录且模型配置有效时可用；缺少模型配置时明确返回 `CONFIG_MISSING`，不发起模型调用。
- 完整离线识别链路：prepare → 上传桩 → recognize → reference，识别“小白菜”、蛋白质 1.4，上传一次、模型桩一次，进入结果预览；不写入食物资料库。参考服务断网后仍可预览，并保留参考不可用提示。
- 扫描页面模拟自定义分类读取失败仍可用；首次相机打开一次，相机返回后不再次打开；相册图片压缩不支持时使用经过大小校验的原图。
- 既有首页、系统食物索引及资料库、食物摄入、喂养换算、营养档案检查共 104 项通过；没有新增或修改测试文件。
- 微信开发者工具原生 `wcc/wcsc` 对首页、搜索页、扫描页及识别组件四组模板和样式离线编译通过。
- 对 320、375、414 像素宽度的首页入口、搜索初始、搜索结果、筛选、预览、扫描就绪及不可用状态共 21 组离线布局进行截图和尺寸检查，交互控件未发现横向溢出。使用实际 WXML/WXSS 转换渲染，不能代替微信运行时或真机验收。
- 两项共享模块构建及一致性检查、改动 JavaScript 语法、Git 空白检查通过。Serena 记忆工具不可用，原因及验证记录保存在本文。

## 云端待同步

本地验证不代表当前生产环境已经恢复。本轮最小部署范围为两个完整云函数目录：

1. `cloudfunctions/searchManager`：普通搜索能力隔离、预筛选、批量查询、及时返回候选及分页。
2. `cloudfunctions/recognizeNutritionLabel`：独立能力接口、上传前模型检查及共享默认开放策略。

`cloudfunctions/featureFlagManager` 可暂不部署。用户询问其线上影响后，核对实际差异确认仅增加管理员 `getSearchScanConfig/updateSearchScanConfig` 接口，已有公告、报告 OCR、开发者身份检查及依赖没有变化；当前前端没有调用新增接口。管理端读操作不会写入缺省开关，只有明确调用更新接口才改数据库。搜索与扫描读取各自云函数内的共享策略，不依赖该管理接口。

使用微信开发者工具 CLI 的完整目录部署及云端安装依赖；不能只上传 `index.js`。部署前先核对生产环境函数及配置，密钥只检查是否存在，不输出原值。既有显式关闭仍生效；若真实开关、集合、索引或模型配置需要调整，先列出实际差异并取得相应确认。

本轮尚未调用生产 API、部署、修改云端开关、创建集合或调用真实模型。“拍照识别不可用”来自服务端开关检查，但实际生产开关和部署副本版本尚未核对，不能仅凭历史部署记录断言实时状态。
