# 首页拍照新增报告识别入口

日期：2026-11-07
工作分支：`codex/home-photo-report`

## 功能与关键决策

- 首页拍照页增加“报告”类目，与“拍食物”“拍包装”并列。
- 使用现有报告识别能力；用户先选择报告类型，再拍照或从相册选取一张图片。
- 拍照保留整张照片，不使用食物取景框裁切；图片通过页面事件通道一次性交给报告识别结果页，不持久化到缓存。
- 拍照后先在独立结果页完成识别，以紧凑的“检验项目／结果／参考范围”三列表格显示已识别指标；提供原图查看、重新拍摄及失败重试。
- 用户点击“确认并创建”才进入创建报告表单；通过页面通道传递已确认的结果，等待指标初始化就绪后填入，不再次识别。
- 结果预览与填写页共用 `pkg-report/utils/reportRecognition.js`，统一压缩、上传、超时、解析和临时文件清理；展示沿用现有填写页的数字格式。
- 未识别到指标或识别失败时不允许确认创建；返回重拍、返回取消均不会新增报告记录。
- 支持血串联质谱、尿串联质谱、血气分析、血常规、血五分类CRP、血氨检测。大生化沿用现有仅支持手动录入的限制。
- 自动填入指标值及可识别的参考范围；检测日期与机构由用户核对填写，报告仍须用户明确保存。
- 报告与食物使用独立权限预检和缓存键；共享报告权限工具设置超时，正式识别继续由服务端校验权限。
- 图片交接、识别结果确认及表单回填均核对宝宝、账号和页面状态；离开页面或切换上下文后不再回填过期结果，已上传的临时文件沿用原有清理流程。
- 表单保存成功后跳过结果预览返回拍照页，避免从同一份识别结果再次创建；未保存返回时仍可继续核对预览。
- 保留进入任务时已有未提交改动；未提交、推送或部署。
