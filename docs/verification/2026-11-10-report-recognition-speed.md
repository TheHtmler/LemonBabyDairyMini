# 报告识别串行等待与重复输入优化

日期：2026-11-10

## 证据与范围

- 用户初次反馈识别慢且显示超时时，尚无同次日志；随后补充请求 `8e299b88-5785-4f19-8abd-defd00a700f7` 的平台错误：`Invoking task timed out after 60 seconds`。这确认该次调用触及平台60秒执行上限，并非模型90秒预算主动返回的超时。
- 本地 `recognizeReportCustom/config.json` 已配置120秒，但该次实际调用仍在60秒被终止，说明线上有效上限尚未与本地预算一致。无法仅凭本地配置或已上传代码断言云端超时配置生效。
- 代码可以确认三处冗余：小程序逐张上传；旧模型四图转录受两个并发限制，要分两轮；归属请求重复携带一张最多12MP参考图，以及不参与名称归属的检测值、参考范围、单位、标记和大量别名。
- 延续原行转录与指标归属分离，不恢复整组长输出，也不通过别名白名单取代模型语义理解。暂停付费验证的约定继续有效。

## 修改

- 小程序 `reportRecognition.js` 将图片上传改为最多三张并行，按原照片位置存储云文件编号；所有图片准备完成后才派发识别。任一上传失败或请求失效时停止新增上传，等待在途任务结束后清理已上传文件，避免漏清理晚完成的文件。
- 旧版多图血报告转录并发从2提高到4，常见四图可在同一轮派发；六图仍有并发上限。全部转录成功后才汇总与归属；原图转录像素预算、固定原行、检测值冲突及错误引用检查保持。
- 归属阶段只发送每行的程序编号与原名称，以及目标编号、名称和缩写。名称未收录仍由模型语义归属；检测值等字段只保留在程序固定原表中，模型返回的编号只能选取该原表。
- 旧版接口仍附带一张图片以满足接口要求，但归属阶段将 `min_pixels`、`max_pixels` 均设为4096，明确只依据文字名称表完成任务，避免再次编码高清图片。原表转录阶段没有降低像素预算。
- 像素预算控制模型服务处理的像素，不会缩小本机Base64原图字节，因此不将其描述为模型端网络上传字节减少。首次上传保留原图清晰度和现有大小上限。
- 正常四图仍为四次转录加一次归属，业务额度仍计一次；并发失败时全部在途请求用量仍累计，不能提前返回遗漏已用额度。本轮没有增加自动重试、提高超时预算或更换管理员选择的模型。
- 解析器版本为 `qwen-report-v11-parallel-compact`，结果日志新增 `sourceConcurrency`，沿用 `sourceBatchCount`、`transcriptionMs`、`mappingMs` 以便部署后比较。

## 验证与限制

- 沿用用户已授权的离线报告解析及流程验证范围。先复现四图需要两轮、上传逐张等待及归属重复携带完整临床字段，再验证四图同轮派发、六图并发边界、乱序完成来源正确、完整汇总后归属、截断停止派发与在途用量结算。
- 上传用例只替代文件与云传输，不加载页面，也不做界面或模拟页面交互验收；验证最多三张并行、照片顺序、失败停止派发及晚完成文件清理。
- 十三个相关离线测试文件共206项通过，相关JavaScript语法、`npm run check:search` 和 `git diff --check` 通过，代码索引已刷新。
- 没有真实OCR调用或付费测速，没有发送报告图片，也没有部署、提交或推送。离线验证证明减少了程序串行等待与归属输入，不能据此承诺真实耗时或超时已消除；服务排队、网络与实际云端执行配置仍会影响结果。
- 需要完整部署 `recognizeReportCustom`（包含 `lib`）并更新小程序，同时在小程序实际调用环境的云开发控制台打开该函数的配置，将执行超时时间设为120秒并保存，再核对保存后的有效值。提速改动减少等待；配置同步解决该次已确认的60秒平台中断，两者分别验证。
- 本机未安装CloudBase管理命令，本轮没有连接生产管理接口或进行控制台操作，线上配置未由本次操作修改。

## 参数依据

- [千问OCR官方接口文档：图像分辨率控制](https://www.alibabacloud.com/help/en/model-studio/qwen-vl-ocr-api-reference)：`min_pixels` 和 `max_pixels` 控制服务处理像素，旧版最小像素为3136，2025快照为3072；4096符合该范围。该说明只支持参数范围，不代表此业务的真实语义归属准确率已验证。
- [CloudBase官方基础配置](https://docs.cloudbase.net/cloud-function/function-configuration/config)：函数详情可设置超时时间，超过执行上限时平台会强制中断；普通事件云函数支持1至900秒，120秒在该范围内。
