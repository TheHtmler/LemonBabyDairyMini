# 搜索页交互精简

日期：2026-10-28。当前分支：`codex/search-data-queries`（原分支为 `codex/simple-search`）。

## 目标与实现

用户已确认采用“输入一句话 → 查看结果 → 打开详情”，降低搜索交互的理解成本。

- 移除分类栏、来源与日期选择器、营养条件表单、可编辑条件标签，以及“继续问／新查询”模式；同步删除对应的状态、事件和样式。
- 每次提交原搜索词都创建完整的新查询；分页、必要的对象澄清、阈值补充和结果明细仍复用当前服务端上下文。
- 资料结果显示数量，记录和统计结果保留日期范围，对比结果保留左右两段日期；来源、计量基准和缺少数据状态继续展示。
- 无结果或失败时提供修改原搜索词与必要的重试入口。列表中缺少比较依据的提示直接显示，指标计算依据继续按需展开，避免重复展示相同说明。
- 保留最近搜索、详情预览、保存返回后的完整查询恢复、新增资料定位、账号与宝宝隔离，以及迟到响应保护。

## 变更范围

仅修改 `miniprogram/pkg-milk/search/index.js`、`index.wxml`、`index.wxss` 和本记录。搜索后端、共享查询协议及原有识别功能的未提交改动不在本次范围。

## 补充：移除拍照入口与快捷搜索示例

后续调整：快捷项已与手动输入统一走模型，专用 `manual` 查询已移除；大按钮已改为小标签。当前实现分别见 `2026-10-29-search-model-first.md` 与 `2026-10-29-search-feedback.md`。

- 按用户后续要求，移除搜索框的拍照入口，以及仅供该入口使用的状态、跳转方法和样式。
- 空搜索页展示“试试这样搜”，提供系统食物浏览、每 100 克蛋白质低于 5 克的系统食物、体重变化、奶量、饮食记录和天然蛋白系数共 6 条示例，移除特定食材和自建食谱示例。
- 两条系统食物示例通过已有查询协议明确指定 `catalog.search / food / source=system`，不依赖模型猜测来源；筛选示例同时明确每 100 克、低于 5 克的基准与阈值。最近搜索再次点击相同文案时也沿用该查询。其余示例继续按自然语言解析，记录结果以宝宝已录入内容为准。
- 示例采用固定两列、等宽按钮，统一 16rpx 间距、20rpx 内边距和 128rpx 最小高度；完整换行显示文案。最近搜索单独设置间距与样式，长文案允许换行。
- 示例与最近搜索同时展示；输入或查询后收起。搜索服务未就绪时禁用快捷按钮，避免发起无效查询。
- 首次进入不自动弹出键盘，方便阅读示例；用户点击输入框、清除内容或选择修改搜索时仍可正常输入。
- `npm run check:search`、搜索页 `node --check`、`git diff --check` 均通过。Acorn 静态检查确认 29 处事件绑定、174 处模板表达式和标签闭合有效，未加载或执行页面控制器。
- 从页面语法树读取静态示例配置，两条系统食物查询均通过已有 `validateIntentDraft` 协议校验器，确认无名称依赖和待澄清项，来源为系统；仅检查数据配置和协议，未执行页面事件或调用模型、数据库。
