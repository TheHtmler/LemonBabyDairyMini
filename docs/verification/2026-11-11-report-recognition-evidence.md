# 血常规、血气等报告原行证据改造

日期：2026-11-11

## 改造内容

- 血常规、血五分类CRP、血气和血氨从单请求直接生成目标数值，改为逐图转录原表，再对固定原行进行名称与单位归属；归属阶段不接收检测值或参考范围，也不能改写原表。
- 复用原行结构校验、程序编号、最多四个转录并发、同次请求缓存、共享截止时间及用量结算。第一阶段字段只接受字符串或空值，避免JSON数字在固定证据前被舍入。
- 新类型保留同指标的所有已确认原行，前端不先压成单个值。原值、原名、原单位、原范围与照片来源贯通核对预览；不同结果或不兼容范围需要选择来源。
- 百分比与绝对值、PCT、MCH/MCHC、标准/实际HCO3、BE(B)/BEecf及离子钙/总钙等有确定的语义与单位检查。未知名称仍可使用模型明确归属，明确矛盾不强塞目标。
- 单位不兼容或关键单位缺失的候选不能通过选择强行交接，其他可靠项目可以继续录入；没有可靠项目时显示没有可回填结果。
- `REPORT_RECOGNITION_VERSION=report-evidence-v1` 同时约束前后端请求/响应和幂等摘要。解析版本为 `qwen-report-v14-source-evidence`；旧客户端或旧云端不静默回退。
- 检测值保留比较符、科学计数法和原精度；`<0.1`不等价于`0.1`。填写、失焦、保存、展示与导出沿用原字符串；状态、差值、趋势和派生比值只接受精确有限数值，非零数下溢为零时也停止计算。
- 自动比值标记为程序派生，只随基础值更新；基础值失效或变成比较结果时清空旧派生值，手工或原图比值保留。
- 同源单位工具用于识别、结果去重和跨报告比较；不同单位或未确认相同尺度时不计算差值、不作为同一趋势测量点，不进行数值单位换算。

## 独立审阅与处理

独立只读代码审阅发现两项重要问题，已修复：

1. 工作台比较和趋势入口缺少单位核对：统一加入单位尺度检查，保留分别的原值与原单位。
2. 首阶段接受JSON数字可能先舍入：原行的n/v/r/u/f严格限定为字符串或空值，类型错误整组拒收。

审阅期间另补齐无冲突项目的原名称展示。未发现需要延期处理的次要问题。

保留的范围决定：血串联继续采用原有冲突整组失败策略与转录范围，尿串联继续使用单阶段调用路径，大生化继续手工录入；本次不扩张上述业务范围。不对没有样本支持的模型实际准确率作判断。
