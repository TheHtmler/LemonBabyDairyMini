# 意见反馈对话式界面优化

## 范围与设计

- 在当前 `codex/search-interaction-polish` 分支继续已有反馈功能，开始时工作区干净。
- 将首条反馈、用户补充、开发者回复统一为左右气泡，详情采用浅灰背景、白色对方气泡与柠檬黄己方气泡。
- 顶部用单行工具条保留问题类型、处理状态、资料入口和刷新，去掉大字头像及重复说明。底部输入框占主要宽度，发送按钮显式限定为 104rpx；管理员可勾选“同时标记已处理”后发送。
- 对话间隔达到五分钟或跨日期时显示时间，今天的记录只显示时分；连续对方消息共用身份标注，己方消息不重复显示“我”。
- 用户列表和详情不展示处理状态，也不提示补充后的状态变化；管理员端保留状态、筛选与待办统计。消息中心的个人反馈摘要统一描述沟通记录。
- 管理员顶部状态改为原生选择器，可在“待处理／已处理”间切换。沿用管理员权限、已回复要求和对话版本校验；切换与发送、刷新、历史加载互斥，状态成功或请求失败后均读取最新详情并保留草稿，失败时在重新读取成功前禁止再次切换或发送。待确认的发送请求确认前不可切换状态。
- 红点统一通过首页消息入口展示，移除底部“我的”、个人页反馈入口、个人反馈标签和条目圆点、旧管理列表筛选圆点。个人页不再为红点订阅或请求统计，菜单点击时仍可依据已有未读状态进入“我的反馈”。身份隔离、首页订阅及详情已读回执继续保留。
- 滚动区独立于顶部与输入栏；按键盘高度调整可用空间。首次打开定位已加载的首条未读回复，无未读则定位最新记录；发送后定位底部，加载历史后定位此前首条记录。
- 未读观察范围同时限制在滚动区与页面内，保留原有按实际展示版本确认已读的机制。没有新增实时推送、轮询或在线状态。
- 提交页和个人列表统一视觉；列表优先展示最近一方的补充或回复摘要。
- 本轮界面和提醒调整没有更改云函数、数据库权限、接口和依赖。用户已要求合入本地 `main`，提交与合并结果以 Git 记录为准；没有部署线上资源。

## 官方资料与审核判断

2026-10-31 通过只读请求获取并解析以下微信官方正文，未登录任何后台：

- [开放的服务类目](https://developers.weixin.qq.com/miniprogram/product/material/)：官方页面注明最后编辑于 2026-10-30。个人主体开放类目中没有社交类目；类目会动态调整，以提交时要求为准。
- [小程序平台运营规范](https://developers.weixin.qq.com/miniprogram/product/)：实际服务和类目需相符，开发者需设置内容安全机制，并遵守用户隐私和数据规范。
- [textarea](https://developers.weixin.qq.com/miniprogram/dev/component/textarea.html)：确认 `auto-height`、`adjust-position`、`keyboardheightchange` 的接口语义，忽略重复键盘高度事件。
- [IntersectionObserver.relativeTo](https://developers.weixin.qq.com/miniprogram/dev/api/wxml/IntersectionObserver.relativeTo.html)：确认以滚动节点作为参照区域的能力。

本实现限定为提交者与固定管理员的封闭问题反馈，沿用云端身份校验与写入前文本安全检查；没有加入用户发现、任意私信或公开讨论。该范围是降低审核误解的设计判断，官方文档没有承诺对话式反馈免审或必然过审。完整小程序仍需核对实际申报类目、隐私声明、数据删除渠道及既有云端发布前置事项。

## 验证范围

- 小程序静态依赖检查通过：69 个页面/组件、392 个文件、446 处引用，包含 JS 语法和分包边界检查。
- 模板静态检查通过：详情页 20 处事件、98 个表达式；反馈页 8 处事件、28 个表达式；个人页 8／24；旧管理列表 8／49。事件均对应现有方法，标签闭合完整。
- 页面 JSON 解析、WXSS 括号结构及 `git diff --check` 通过。
- 首轮独立只读审阅发现浅色导航背景会继承全局白色导航文字，已在反馈页和详情页显式改为黑色。
- 根据用户提供的截图再次收紧布局，显式覆盖小程序按钮默认宽度，避免发送按钮挤占输入区；复审发现处理请求超时后刷新可能丢失原模式的重试入口，已用 `retryMode` 保留原模式并显示“重试”，不确定结果确认前禁止切换处理选项。再次只读复核通过，未发现其他可确认问题。
- 按用户约定，没有新增或修改单元测试，没有启动服务、浏览器、模拟页面或进行界面验收；静态检查不能代替微信编译器与真机交互确认。
- 发布说明见 [反馈回复功能使用与发布说明](../miniprogram/feedback-replies.md)，本地界面改动不会自动部署既有持续追问功能。
