# 拍照识别动画与结果浮窗

日期：2026-10-20。

## 本次依据与范围

用户提供薄荷健康的识别中、识别完成截图，要求用照片背景、简洁识别动画和底部结果浮窗替代大段说明；空值显示“未识别”，移除“查看依据”等复杂内容。

用户已明确：此前只重新编译了小程序，没有重新部署 `recognizeNutritionLabel`。因此前两轮服务端标签单位归一化、表头解析与模型提示修改尚未生效。本次集中调整展示，不继续叠加未经线上验证的模型或解析改动。

## 实现

- 首次识别在拍摄照片上显示旋转扫描环和短状态文字；随真实处理状态切换，不显示虚构百分比。请求结束后展示结果浮窗，失败则展示错误与重试入口。
- 结果浮窗按名称、计量基准、热量、碳水／蛋白质／脂肪、膳食纤维／钠排列；底部保留“重拍”和“核对保存”。
- 缺失字段显示“未识别”；真实的零值正常显示，不把非零微量值舍入成零。AI 估算和未完成基准换算的标签读数保留短标记。
- 移除预览步骤条、逐字段依据列表、来源说明段落、缺项解释长文和默认类型调整入口；类型确实不明确时仍可选择。
- 仅包装标签缺少主要营养值时出现“补拍营养表”；实物照片不会被要求补拍不存在的标签。
- 保留身份确认、生熟状态确认、参考候选、基准确认、草稿恢复、查重及保存恢复。后续查询或估算在浮窗内更新，不重复进入全屏扫描。
- CSS 支持减少动态效果偏好；照片背景在预览阶段使用，保存核对继续使用原有表单。
- 原始标签依据仍保留在识别会话与草稿中；移除的是结果页展示，不改变保存决策和营养数据来源。

修改集中在 `miniprogram/pkg-milk/components/nutrition-recognition/` 的 `index.js`、`index.wxml`、`index.wxss`、`dialogState.js`、`evidenceView.js`。
