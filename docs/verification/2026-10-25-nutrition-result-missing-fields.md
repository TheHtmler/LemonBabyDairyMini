# 缺失营养在对应结果指标中显示

## 用户要求

包装食品缺少营养读数时，继续显示正常识别结果，并在对应指标展示“未识别”；不使用单独的缺营养提示页面。

## 修改

- 删除缺营养专用提示块、隐藏整组营养指标的条件，以及该状态的照片和弹窗尺寸样式。
- 热量、蛋白质、碳水、脂肪、膳食纤维和钠继续使用同一结果布局：成功读数显示一位小数，缺失显示“未识别”。真实零仍显示 `0.0`。
- 删除顶部直接展示内部逐项校验文字的警告块；原始警告仍保留在识别结果中，字段冲突继续在对应指标提示“待核对”，详细核对表单的冲突提示和保存校验保留。
- 缺少名称时继续允许在原结果页确认名称；预览操作统一为“应用结果”，进入已有添加表单后仍需补齐必填营养才能保存。
- 删除不再使用的页面投影、初始化状态和样式，没有修改识别模型、图片保存或云端写入规则。
