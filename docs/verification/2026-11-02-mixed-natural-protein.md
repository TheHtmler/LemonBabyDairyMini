# 天然混合蛋白录入与统计

## 实现范围

- 分支：从干净的 `main` 创建 `codex/mixed-natural-protein`。
- 食物管理与拍照识别的添加表单增加“天然蛋白（混合）”，保留旧选项索引；蛋白来源旁的问号按钮展开说明气泡。
- 共享成分编辑器支持多行增删、我的／系统优质食物搜索与手填。引用保存当次名称和每100g蛋白数据，手填不创建食物库条目。
- `proteinComposition` 包含每100g成品的质量基准与优质成分数组，每行保存用量、百分比／克数、蛋白质含量和来源ID；录入前固定显示“约”，不提供比较符选择。
- 克数和百分比均对应每100g成品，按填入数值进行参考估算；原料添加比例需要先换算到成品重量。
- 食物总蛋白沿用原营养数据；各行贡献合计为优质蛋白估算，剩余默认普通；缺项、非法数值、参考用量合计超100g、优质贡献超标签总蛋白时阻止保存。
- 缺少质量换算的毫升或份数基准不直接参与混合拆分；需以克为营养基准。
- 普通食物、食谱原料、摄入记录、餐次和日汇总共享同一拆分函数。含混合食品的优质克数带“约”，包括零贡献与统计页平均克数。
- 食物库、摄入记录和食谱快照携带明细；历史混合快照优先于后来修改的食物库。日汇总记录混合条目数，目标预览编辑时可清除已移除混合条目的标记。
- 不复用原天然／特殊蛋白拆分 `proteinSplit`，不批量修改历史记录，不新增依赖。
