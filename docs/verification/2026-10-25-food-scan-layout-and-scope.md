# 食物识别布局统一与奶粉识别停用

- 碳水、脂肪调整为名称与来源标签在上、数值在下，与其他指标保持同一阅读顺序；相应间距放到数值行。
- “营养对比”按钮显式使用弹性布局水平与垂直居中、居中文本和不换行，保留至少 44px 点击区。
- 拍摄页移除食物／奶粉类型选项，改为“拍食物／拍包装”两种采集方式：食材或餐食拍全貌，有营养成分表的食品拍营养表和包装正面。两种方式均使用自动类型判断，不要求用户区分“纯食物”。提示说明奶粉应按包装手工填写。
- 移除奶粉管理页的拍照入口、识别组件、回填事件及识别专用状态；奶粉和母乳继续使用原手动保存接口，未完成保存的保护仍保留，并提示到拍照识别页恢复状态。原有营养来源与缺失数据仍可读取。
- 共用的 `assertFoodRecognition` 拦截奶粉类型、干粉／冲调液基准及明确奶粉身份，覆盖识别请求、自动分类结果、旧缓存、预查／绑定、参考查询、估算及确认保存。前端在采用结果前同样校验，防止只更新一端时继续回填奶粉结果。
- 已保存资料仍允许幂等读取和恢复；手动奶粉管理、已有奶粉资料和历史记录不受识别停用影响。移除不再使用的奶粉分类目录及识别类型参数。
