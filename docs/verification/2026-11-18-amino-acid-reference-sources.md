# 氨基酸参考数据

按系统食品编号收录 156 条公共成分参考。详情的九种必需氨基酸中，147 条齐全，5 条有八项，4 条有三项。每日汇总的五项仍有 152 条齐全。每条对应一个官方条目，带原始样品名、版本、查询链接和编号。

- USDA FoodData Central SR Legacy 2018-04 有 136 条，Foundation 2026-10-29 有 3 条。按 FDC ID 定位营养成分。两份压缩档 SHA-256 前 12 位分别为 `b80817294b88` 和 `dd414cc9f1a1`。[数据下载](https://fdc.nal.usda.gov/download-datasets)
- 台湾食药署食品营养成分资料集 17 条。数据为 2026-11-17 取得的 2026-10-05 JSON 快照，压缩档 SHA-256 前 12 位为 `755d2f0e4a7c`。可在原始文件中按「整合編號」定位样品。[资料集与开放授权](https://data.gov.tw/dataset/8543)
- 国内数据作为后续来源。国家人口健康科学数据中心目录列有 657 条，原始数据需申请。待核实原始数值及复用许可后再考虑收录。[数据目录](https://www.phsciencedata.cn/Share/ky_sjml.jsp?id=577e0301-ab65-432a-9bb7-a8342302e589)

## 选取与核对

以 `amino-food-coverage.csv` 和 `amino-usda-sources.csv` 中人工初核的食品对应为基础，按原始成分表核对品种、部位、生熟、干湿和加工形态。通过筛查的同身份样品优先采用 USDA，缺少可用 USDA 样品时采用台湾食药署资料。一个来源有多个可用样品时优先选五项齐全的条目，完整度相同时参考样品说明和蛋白质、水分接近程度。

每项以每 100 克可食部的毫克数表示。USDA 原始数值由克转换为毫克。与官方或系统食物蛋白质量纲冲突的候选排除，并沿用先前的样品差异筛查。蛋白质差至少为 2 克且达到较大值的 30%，或水分差至少为 15 克的候选暂缓采用。

每条食品保留系统食物库的原始营养计量单位、基准量和六项营养基线。公共来源的氨基酸作为估算参考，每条记录只保留一个样品。扩展详情时，赖氨酸、苯丙氨酸、色氨酸和组氨酸均从已选的同一官方样品读取。原表留空或为缺少实测说明的 0 时保留缺项。冬瓜、红薯叶、鲜荔枝和荔枝干在每日汇总五项中只有蛋氨酸可用。USDA 油脂候选中，五项全为零且没有测定点或零值说明的条目暂缓采用。

## 自定义食物搜索库

「我的食物」的氨基酸搜索使用云函数 `searchAminoAcidReferences` 随包发布的 `references.json`。候选库收录 6,680 个官方样品，包括 USDA SR Legacy 4,992 条、USDA Foundation 107 条和台湾食药署 1,581 条。使用上述官方快照，无需 USDA API Key。

导入脚本保留来源、样品编号、已核对别名和原表可识别的生熟或加工状态。每条至少有一个可用的必需氨基酸数值，原表缺项保留。氨基酸合计超过同一样品蛋白质的 18 条未收录。原表未明确生熟时，候选标为「生熟未标明」。应用时把选定样品的数值和来源存入个人氨基酸档案，保留已手填的项目。

搜索统一全半角、大小写和标点，使用已有的简繁名称、俗名和连续字符片段匹配。跨语言候选来自原始样品的中英文名。原库的食品分类和形态用于排序，明确输入的生熟状态用于筛选。应用参考值前会校验食物身份、计量口径和可比较的成分，高匹配校验未通过的候选仅供查看。

使用官方压缩档在仓库根目录刷新候选库。脚本需要 Python 3.9+、Node.js 和简繁转换工具，macOS 使用系统 CoreFoundation，其他平台可用 ICU 的 `uconv` 或 OpenCC。

```bash
python3 scripts/import-amino-acid-references.py \
  --sr-legacy "SR Legacy CSV 压缩档路径" \
  --foundation "Foundation JSON 压缩档路径" \
  --tfda "台湾食药署 JSON 压缩档路径"
```

上线时先部署完整的 `cloudfunctions/searchAminoAcidReferences` 目录，再发布小程序。当前小程序接收 v3 搜索结果，旧版结果会触发随包搜索。
