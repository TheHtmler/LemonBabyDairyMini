# 拍照返回按钮与自动分类修正

## 本轮变更

- 拍照页与识别预览共用本地透明 PNG 返回图标，分别使用 `cover-image` 和 `image`。显示尺寸 24px，点击区至少 44px，左边界保持为 0。
- 导航顶部按微信胶囊中心计算：`menu.top + (menu.height - navHeight) / 2`。识别中与结果页直接复用该位置，避免 44px 返回按钮与较矮胶囊只对齐顶部产生偏移。
- 拍照页的奶粉、食物标签都使用自动识别；标签保留为取景提示，图片中的真实产品类别决定结果与保存目标。原有添加、编辑表单的指定识别类型不变。
- 删除识别结果的“食品包装／奶粉标签／食物实物”选项与重新选择类型的请求逻辑。自动识别为奶粉时，不再因从食物入口进入而拦截。
- 模型按产品类别区分奶粉与普通粉状食品；罐装、粉末、需冲调、婴幼儿食用或含奶不能单独作为奶粉依据，米粉仅作规则示例，不增加品名匹配分支。
- 同一商品多张照片只读到部分品牌、系列、规格时，不再把缺字段当作商品冲突；同一字段实际冲突、不同条码或模型明确检测到多件商品仍阻断使用。
- 无法判断时，仅显示简短提示及补拍、重拍入口；最多三张，图片已满或内容不是食品时提供重拍，不显示不可用的保存按钮。未知类别仍禁止保存。
