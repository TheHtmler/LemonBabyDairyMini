# 隐藏报告拍照识别入口

按用户要求，报告拍照识别调试期间暂时隐藏入口，保留识别实现及已有报告数据。

- 在 `miniprogram/utils/reportOcrAccess.js` 使用 `REPORT_OCR_ENTRY_ENABLED = false` 统一控制前端入口；关闭时直接返回不可用，不调用云端权限预检。
- 隐藏拍照页的“报告”选项，并阻止切换到报告模式；新增、编辑报告页沿用统一预检结果隐藏“拍照或多选报告”。
- 移除报告列表空状态及拍摄提示中对报告拍照识别的引导。
- 食物、包装识别和报告手动录入、查看、对比、导出保持原有流程。已有原报告图片仍可查看。
- 以后恢复入口可将统一开关改为 `true`，仍需通过现有云端权限和模型配置校验。

验证仅限 JavaScript 语法、静态依赖与差异检查；不新增或修改单元测试，不进行界面验收、启动服务或部署。
